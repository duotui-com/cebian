闪念 · 贴边把手 + 两页签面板

屏上只有一个常驻元素：一条贴边把手（视觉 9×28dp，命中区 48×48dp 达安卓最小触摸目标）。
它就是你已有的那个剪贴板把手——不是新长出来的第二个。原来的剪贴板面板本来就是两页签（暂存夹 / 剪贴板）， 所以合并只是把「暂存夹」页签改名成「闪念」并把暂存内容彻底并进这一个流（连「含暂存」开关都不要了）： 一个把手、一个面板、两个页签，零新增表面，也没有范围过滤。
入口三条：① 拖 / 点把手 → 面板 ② 长按把手 → 直接就记 ③ 手势动作「闪念速记」→ 配到触发条 / 悬浮球。
这次补上的：卡片操作行真的接上了（复制 / 星标 / 更多菜单）· 待办可「完成」（划掉 + 撤销 + 自动取消提醒）· 存下 / 删除 / 完成都能撤销 · 面板有搜索（标题栏和页签本来重名，腾出来放它）· 闪念与暂存彻底合并（去掉「含暂存」开关）· 「完成」只在待办条目上出现· 空状态引导 · 存下后浮出内容预览。

这一轮补的东西

  • 操作行接上了：行内只留高频（完成 / 复制），其余收进 ⋮ 菜单。这样 5 个动作才装得下 48dp 触摸目标——全放行内会 240dp 超卡片宽
  • 待办可完成：划掉 + 变暗，留在原位（不移除，时间流是「我记过什么」的历史）；完成即自动取消提醒
  • 撤销：存下 / 删除 / 完成，通知条上都有「撤销」
  • 搜索：标题栏和页签本来重名（都写「闪念」），把它腾出来放了搜索框；搜索会忽略标签筛选和范围，就近搜整个页签
  • 空状态：一条都没有 / 筛不出来 / 搜不到，三种各有引导
  • 存下预览：把手旁浮出内容前十几字，1.2s 消失。这是「刚发生的事」，不是常驻物——和被砍掉的胶囊不是一回事
  • 提醒可见：设了提醒的条目，时间旁边显示钟点

与仓库既有资产对应

  • 把手 → HistoryFloatService（常驻窗 / 可拖 Y / 位置持久化 / 全屏与横屏隐藏）——复用它，不新建
  • 返回手势避让 → OverlayPanelSystemGestureExclusion（只排除把手自己的 48×48，且位置变化时要重设）
  • 长按时长 → 跟 ViewConfiguration.getLongPressTimeout()，不要写死
  • 输入法 → SearchPanelOverlayWindow 抢焦点 + 补发三件套 + OverlayImeInsets
  • 搜索 → SearchPanelOverlayWindow 既有的搜索面板范式
  • 数据 → StashRepository + 独立 tags.json；done 也要独立存——写进 index.json 的老版本会忽略它并整体重写，完成状态就丢了
  • 提醒 → RemindAlarmScheduler（推送，不占屏）
  • 玻璃 → LocalFrostedGlassBackdrop（禁 miuix RuntimeShader，浮层会崩）
02八个关键状态

① 屏上唯一常驻元素 ② 长按把手直接记 + 存下预览 ③ 往内拖跟手拉出 ④ 闪念页（搜索 + 标签，不再有范围开关） ⑤ ⋮ 溢出菜单 ⑥ 待办完成与提醒 ⑦ 空状态 ⑧ 剪贴板页

玻璃：跨应用真模糊 + 手写顶部光泽 / 内高光 / 内阴影 / 噪点 0.045｜禁 miuix RuntimeShader（浮层软件 Canvas 会崩）｜标签颜色仅 5px 色点与选中描边着色。
Android 规范：触摸目标 ≥ 48dp；横向列表隐藏滚动条、只管滑。桌面演示稿里的鼠标拖拽滚动属于脚手架，不是设计。
